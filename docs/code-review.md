# 代码审查与修复

## 已发现问题

1. 原实现把 zcode-keysmith 和状态栏目录硬编码到设置里的插件根目录；如果用户改了插件根目录，安装会指向错误位置。
2. “刷新”没有使用设置页中新输入的插件根目录，需要先保存才生效，交互不明确。
3. 原实现只支持两个固定插件目录，无法承接后续从 GitHub 添加的插件。
4. 详情页只显示手工摘要，没有展示插件 README 原文。
5. 安装器类型不足，不能识别常见的 `install.py` 与 `install.ps1`；完全无安装器的仓库会被当成未知状态。
6. 更新操作没有区分“源码更新”和“更新后重装”；对未安装插件重装没有必要。
7. 删除插件和 GitHub 添加入口没有实现。

## 修复方式

- 插件目录、README、安装命令均从当前 `PluginDefinition` 传入，不再从设置拼接固定插件名。
- 使用 `GitService` 统一处理浅克隆、`git pull --ff-only` 和 URL 归一化。
- `PluginCatalog` 继续精确识别两个现有插件，并为通用 `install.py`、`install.ps1` 以及只读 GitHub 仓库提供页面。
- `ProcessRunner` 固定使用进程参数数组，避免 shell 注入；新增同步方法供目录扫描读取 `remote.origin.url`。
- UI 增加空态、GitHub 添加面板、卡片删除、详情页删除和 README 阅读区。
- 更新操作先拉取代码；只有插件已安装时才自动重新安装。
